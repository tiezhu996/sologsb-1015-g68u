# 古诗格律校勘台

面向诗词编辑与校勘人员的浏览器工作台。可逐字标注平仄、韵组和停顿，建立对仗关系，记录每条判断依据，并对多个异文版本进行并排定位。

## 功能

- 录入诗句并按五言、七言格律模板逐字对照。
- 平仄、停顿、韵组、判断依据和批注可逐字维护。
- 自动提示出律位置、一三五位置可接受变体、待标字和重复用韵。
- 建立句间对仗关系，记录关系说明。
- 多版本独立校勘，字符级并排比较与上下处差异定位。
- 文档级撤销/重做、键盘巡校和浏览器本地持久化。
- 导出包含字音标注、检查记录和版本来源的 Markdown 校对稿。
- 针对平板和桌面优化布局，支持长时编辑。

## 编辑会话与后台分析（长文不卡顿）

- **会话分离**：正文编辑会话（信号）与后台格律分析批次完全独立，输入与批注不再触发整篇同步重算。
- **批次排队**：超长内容按句切批（默认每批 40 句），串行入队、逐批让出主线程；两千句实测无长任务阻塞。
- **唯一已确认版本**：字格与异文对照都只读取同一个“全部批次成功后确认”的分析版本，绝不显示中间结果。
- **编辑即作废**：编辑中的版本，其排队/在跑批次立即作废；输入与批注继续可用。视图按行指纹遮蔽过时结论，未算完的句子明确标“待分析”。
- **失败回滚与续跑**：批次失败保留上一版完整结果，错误与检查点落 localStorage；重开页面或点击“从检查点继续”从断点恢复。
- **虚拟滚动**：字格与异文对照使用 CDK Virtual Scroll，只渲染可视区间的句子。
- **校对稿诚实标注**：已算完段落标“已算完”并附结论，未算完段落写“待分析”，不以旧结论冒充。

## 技术栈

- Angular 19（standalone components）
- TypeScript
- NG-ZORRO
- RxJS 与 Angular Signals
- Less
- 原生 `localStorage`

## 本地开发

```bash
npm install
npm start
```

浏览器打开终端提供的本地地址。

## 生产构建

```bash
npm run build
```

生产文件位于 `dist/app/browser/`。

## 测试

- Karma/Jasmine（需本机 Chrome）：`npm test`
- 无 Chrome 环境下的逻辑测试（esbuild 编译后在 Node 直跑）：

```bash
node scripts/engine-test.mjs   # 批次排队 / 作废 / 失败回滚 / 检查点续跑
node scripts/store-test.mjs    # 行指纹遮蔽 / 校对稿导出 / 异文门控 / 撤销合并
```

## 键盘操作

| 快捷键 | 操作 |
| --- | --- |
| `↑ / ↓ / ← / →` | 在字格中移动 |
| `1 / 2 / 3` | 标为平 / 仄 / 中 |
| `R` | 循环切换韵组 |
| `Space` | 切换停顿标记 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl/Cmd + Y` | 重做 |
| `Ctrl/Cmd + S` | 本地保存提示 |

## Docker

容器内由 nginx 监听端口 `80`，源码不硬编码宿主端口。

```bash
docker build -t classical-poetry-meter-editor .
docker run --rm -p 10015:80 classical-poetry-meter-editor
```

宿主端口 `10015` 仅用于本地运行示例，实际端口由根编排文件统一管理。
